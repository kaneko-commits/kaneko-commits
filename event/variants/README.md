# 比較用の2つの版

本番の `event/mansion.html`・`event/apartment.html`（D：駅チカ・向いてる人を冒頭に置いた3章構成）とは別に、比較のための版を置いています。
どちらも `python3 build.py` でそのフォルダの中にページを作り直せます。写真は `event/img/`、アイコン類は `flyer/build.py` を共用しています。

| フォルダ | 内容 |
|---|---|
| `a-connected/` | **A接続版**：Aの並び順と中身はそのまま。各セクションの冒頭に、前のセクションを受ける一文（線と小さな見出し）を足しました。家族4人（夫婦＋子ども2人）も明記。 |
| `d-short/` | **D短縮版**：Dの冒頭を短くした版。駅チカの話を3行の表に絞り、同じ枠に「向いてます」だけを置きました。「不向きです」と「前身は設計事務所」は相談会の前（ご来場の前に、知っておいてほしいこと）へ移動。 |

確認用の1ファイル版は、それぞれの `single/` にあります。
