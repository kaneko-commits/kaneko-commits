# S様邸 完成見学会 イベントページ

チラシのQRコードからリンクする予約ページです。チラシと同じ2つの版があります。

| ファイル | 対象 | チラシ |
|---|---|---|
| `mansion.html` | 分譲マンションにお住まいの子育て世帯 | マンション版（「走らないで！」って、本当は言いたくない。） |
| `apartment.html` | アパートにお住まいの子育て世帯 | アパート版（駅チカがいい。でも、マンションは嫌。） |

- 元データは `build.py` です。`python3 build.py` で2つの版をまとめて作り直せます。
- アイコン・暮らしのポイントは `../flyer/build.py` の内容を使っています。チラシを直すとページにも反映されます。
- `single/` には、写真を埋め込んだ確認・共有用のHTML（ファイル1つでブラウザで開けます）ができます。
- 公開するときは `mansion.html`・`apartment.html`・`img/` をまとめてアップロードしてください。
- QRコードのURLに `?from=flyer` を付けると、どのチラシから来たかが予約データ（`source`）に残ります。版は `variant`（mansion / apartment）に入ります。

## ページの流れ
前半（Chapter 01）でS様邸の話を完結させ、完成見学会としての価値づけを終えます。後半（Chapter 02）で、S様が選んだ MinQA とその理由を伝えます。

- 外観とキャッチコピー
- **Chapter 01：S様邸**
  - 心の声（版ごとに内容が違います）→「S様ご夫婦の家づくりも、そんな毎日の想いからはじまりました」
  - S様ご夫婦が描いた3つの想い（校区・駐車場3台・庭は少しでいい）と、それぞれの理由
  - 想いを形にした家（敷地・延床面積・駐車場・家族）
  - 見学会の概要と予約ボタン
  - 想いが形になった家で、毎日はこう変わります（いまの暮らしとS様邸の比較）
  - 共働きのご夫婦の平日を、S様邸で想像してみると（タイムライン）
  - はじめてのご相談から約1年2ヶ月（家づくりの流れ。いま、ここ）
  - 見学会に来るとこんなことがわかります／こんな人に向いてます・不向きです／前身は設計事務所
  - 予約ボタン（お引渡し前の、いまだけ見られる家です）
- **Chapter 02：S様ご夫婦が選んだのは MinQA**
  - MinQA（Minimum Quality Architect）の名前の説明と考え方
  - Reason 01 どの時期にも住みやすい（子ども部屋の変化）
  - Reason 02 将来も売れる・貸せる（サイズ感・間取り構成・駐車場の取り方）
  - Reason 03 その品質を数字で確かめられる（耐震等級3・断熱性能等級6・UA値0.45・C値0.4実測・全熱交換型第一種換気・長期優良住宅はMinQAの標準）
  - Reason 04 建物は広さごとに定額（価格表・土地2,000万円の場合の総額例・ローンの試算は見学会で＋予約ボタン）
- 見学会でできる相談と予約特典（版ごとに内容が違います）
- よくあるご質問（版ごとに内容が違います）
- 予約フォームと電話番号

ページの途中（見学会の概要・Chapter 01の最後・ローンの案内）にも予約ボタンがあります。
スマホでは、画面の下に「電話する」「Webで予約」のボタンが常に表示されます（予約フォームが見えている間は隠れます）。

## 公開前に埋める箇所（ページ上の黄色い点線【要確認】）
ページ上の項目：日時・組数・見学の所要時間・大分駅からの分数・価格の時点・タイムラインの月・受付時間・住所/許可番号・価格の内訳。ほかに次の項目があります。

- [ ] **予約フォームの送信先**：`build.py` の `<form id="form" action="">` に、フォームサービス（Googleフォーム、formrun など）の送信先URLを入れてください。
  - 空のままだと送信されず、完了メッセージが表示されるだけです（動作確認用）。
  - 送信先のサービスに合わせて、項目名（`name` 属性）の調整が必要な場合があります。
- [ ] 予約フォームの希望日時の選択肢（日付と午前/午後の分け方）
- [ ] よくあるご質問「共働きで平日は時間がとれない」の回答：打ち合わせの対応（土日・オンラインなど）
- [ ] 「こんな人には不向きです」と「営業マンはいませんが、家をつくることのプロです」の表現が会社の方針と合っているか
- [ ] S様の3つの想いに添えた理由（学校と職場が近い／夫婦それぞれの車と来客／手入れに追われない庭）がS様の実際の想いと合っているか
- [ ] プライバシーポリシーへのリンク
- [ ] 公開URLを決めて、チラシのQRコードを作成する

## 確認事項
- 商品名は「MinQA」（Minimum Quality Architect の略。資産性と過ごしやすさを担保した住宅）です（`build.py` の `PRODUCT` で変更できます）。チラシ（`flyer/`）はまだ「essence atelier」のままです。
- デザインは、共働きの公務員・銀行員世帯を想定して、落ち着いた上質なトーン（明朝体の見出し、細い罫線、控えめな色数）にしています。
- 会場は「大分市・金池小校区／詳しい場所はご予約時にご案内」としています。施主様のお住まいの場所を公開しないためです。
