# S様邸 完成見学会 イベントページ

チラシのQRコードからリンクする予約ページです。チラシと同じ2つの版があります。

| ファイル | 対象 | チラシ |
|---|---|---|
| `mansion.html` | 分譲マンションにお住まいの子育て世帯 | マンション版（「走らないで！」って、本当は言いたくない。） |
| `apartment.html` | アパートにお住まいの子育て世帯 | アパート版（駅チカがいい。でも、マンションは嫌。） |

- 元データは `build.py` です。`python3 build.py` で2つの版をまとめて作り直せます。
- アイコン・暮らしのポイントは `../flyer/build.py` の内容を使っています。チラシを直すとページにも反映されます。
- `single/` には、写真を埋め込んだ確認・共有用のHTML（ファイル1つでブラウザで開けます）ができます。
- 公開するときは `mansion.html`・`apartment.html`・`img/` をまとめてアップロードしてください。
- 計算欄で選んだ広さと入力した土地価格は、予約データ（`sim_size`・`sim_land`）にも残ります。
- QRコードのURLに `?from=flyer` を付けると、どのチラシから来たかが予約データ（`source`）に残ります。版は `variant`（mansion / apartment）に入ります。

## ページの流れ
1. 外観とキャッチコピー（チラシの表面と同じ）
2. 見学会の概要（日時・会場・参加費）と予約ボタン
3. いまのお住まいのお悩み
4. いまの暮らしとS様邸での暮らしの比較、月々の住居費の比較
5. S様邸の概要と、暮らしの6つのポイント（間取り図は載せていません）
6. atelier の考え方（暮らしの変化に応える間取り）と、定額制の価格表に土地価格を当てはめて総額の目安を出す計算欄
7. S様の家づくりの流れ
8. 見学会でできる相談と予約特典（版ごとに内容が違います）
9. よくあるご質問（版ごとに内容が違います）
10. 予約フォームと電話番号

スマホでは、画面の下に「電話する」「Webで予約」のボタンが常に表示されます（予約フォームが見えている間は隠れます）。

## 公開前に埋める箇所（ページ上の黄色い点線【要確認】）
チラシと共通の項目（日時・組数・大分駅からの分数・月々の比較・総額例・価格の時点・耐震/断熱等級・タイムラインの月・受付時間・住所/許可番号・価格の内訳）に加えて、次の項目があります。

- [ ] **予約フォームの送信先**：`build.py` の `<form id="form" action="">` に、フォームサービス（Googleフォーム、formrun など）の送信先URLを入れてください。
  - 空のままだと送信されず、完了メッセージが表示されるだけです（動作確認用）。
  - 送信先のサービスに合わせて、項目名（`name` 属性）の調整が必要な場合があります。
- [ ] 予約フォームの希望日時の選択肢（日付と午前/午後の分け方）
- [ ] プライバシーポリシーへのリンク
- [ ] 公開URLを決めて、チラシのQRコードを作成する

## 確認事項
- 商品名は「atelier」です（`build.py` の `PRODUCT` で変更できます）。チラシ（`flyer/`）はまだ「essence atelier」のままです。
- デザインは、共働きの公務員・銀行員世帯を想定して、落ち着いた上質なトーン（明朝体の見出し、細い罫線、控えめな色数）にしています。
- 会場は「大分市・金池小校区／詳しい場所はご予約時にご案内」としています。施主様のお住まいの場所を公開しないためです。
