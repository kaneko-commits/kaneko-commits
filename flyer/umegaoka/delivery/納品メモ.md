## ねらい
- ターゲット：築25〜40年の家に住む60代のご夫婦（子ども世代向けの要素は入れていません）
- 切り口：「あと何年住もうかな？」から、建て替えかリフォームかを考える
- 取ってほしい行動：相談会の電話予約
- 金額は載せていません

## 構成
- **表面**：「あと何年住もうかな？」から考える → 建て替えか、リフォームか 相談会 → 相談会のご案内（日時・会場・参加）→ 困りごと4つの吹き出し → リフォーム／建て替えの写真 →「どちらか一方を勧めません」→ 電話予約
- **裏面**：困りごと4つ × リフォームなら／建て替えなら の表 → あと何年住もうかな？（10年なら／20年以上なら）→ 梅が丘の家が考えどきの理由3つ → スタッフ3人 → 相談会の流れ → 電話

## 確認事項
- [ ] 裏面の表の「リフォームなら／建て替えなら」の内容が、自社の提案と合っているか
- [ ] 「あと10年くらいならリフォーム、20年以上なら建て替えも選択肢」という目安でよいか
- [ ] 熱中症・ヒートショックは「寒暖差を小さく」までにとどめ、効果は言い切っていません。表の下に「体調のことは、かかりつけのお医者さまにも」と注記しています
- [ ] 理由02の補助制度は2025年度の大分市の資料によるもの。配布時点の制度を大分市住宅課で確認してください
- [ ] 写真：「建て替え」側は新築の施工例（吹き抜け）、「リフォーム」側はキッチン。リフォームの施工例でなければ差し替えを検討
- [ ] 梅が丘での施工実績があれば、「梅が丘の○○様邸」として載せると効果的です

## 住める版の違い
- 表面の吹き出し：床のきしみ／外壁・基礎のひび／天井・壁の雨じみ／地震への不安
- 裏面の表：「相談会で診る、5つのところ」（基礎・土台、耐震、屋根・外壁、シロアリ、配管・断熱）ごとに「リフォームで延ばせる／建て替えも考えたい」の目安
- 吹き出しと表の内容は、こちらで家の傷みの観点から書いたものです。自社でよく見る症状に合わせて差し替えてください
- [ ] 「家を診る」（ご自宅での診断）が無料かどうか。住める版では診断が主役なので、無料なら明記をおすすめします

## 2つの版の使い分け（案）
- 同じ相談会で、半分ずつ配って反応を比べる（電話で「どちらのチラシを見たか」を聞く）
- 住もう版は暮らしの不便を感じている人に、住める版は家の傷みや地震が気になっている人に届きやすい
